# 🌤️ Weatherly

Weatherly is a modern and responsive weather application built using HTML, CSS, and JavaScript. It provides real-time weather information, hourly forecasts, and a 5-day forecast using the OpenWeather API.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature and weather conditions
- 💧 Humidity, wind speed, pressure, visibility, and feels-like temperature
- 🕒 Hourly forecast
- 📅 5-day weather forecast
- 🌙 Dark and Light mode toggle
- 🎨 Dynamic background based on weather conditions
- 📱 Fully responsive design
- ⚡ Powered by OpenWeather API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API
- Lucide Icons
- Google Fonts (Poppins)


## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/weatherly.git
```

### Open the project

Simply open `index.html` in your browser.

## 🔑 API Configuration

Get your API key from OpenWeather and replace:

```javascript
const API_KEY = "YOUR_API_KEY";
```

with your own API key in `script.js`.
